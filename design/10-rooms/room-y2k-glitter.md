# Custom Room — Y2K Glitter

## Purpose

Prove that the same Room information model can become dramatically expressive without compromising navigation, privacy, or readability.

## Visual direction

Silver-lilac metallic gradients, pixel stars, translucent pink panels, chrome details, sticker-like photo frames, and playful compact labels. The content order and semantic structure remain identical to the default Room.

## Safety boundaries

- Trusted black/gold header and audience controls remain unchanged.
- No animation is required; reduced motion disables sparkle movement.
- Content text uses a readable sans, not novelty pixel typography.
- Custom layers stay inside the Room container and below shell z-index.
- No custom JavaScript; this artboard does not imply unrestricted HTML.
