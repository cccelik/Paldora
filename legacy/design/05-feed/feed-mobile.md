# Home Feed — Mobile

## Purpose

Deliver the same chronological, privacy-explicit feed as desktop through native-feeling mobile ergonomics.

## Layout

390×844 reference canvas with safe areas, 56px top bar, one scroll column, and 72px bottom navigation. Cards have 16px outer margins and 16px internal padding. Media may reach card edges while metadata remains inset.

## Navigation

Home, Boxes, Create, Memories, Profile. Search and notifications are 44px targets in the header. Labels remain visible.

## Interactions

Audience details open a bottom sheet. Comment and more actions use sheets. Double-tap-to-react is optional and never the only path. Pull-to-refresh is paired with explicit status feedback.

## States, privacy, accessibility

Uses the desktop feed data and authorization contract. Dynamic text may increase card height without truncating content. Sticky navigation respects keyboard and safe areas. Reduced motion disables animated refresh and decorative sparkle.
