# Theme Editor — Mobile

## Purpose

Provide focused Room customization without squeezing the desktop three-pane editor into a phone.

## Layout

Safe-area header with close, draft status, and Publish. A 16:10 live preview occupies the top. Scrollable tabs—Theme, Colors, Layout, Widgets, Advanced—control a contextual panel below. Persistent preview/publish actions stay above the home indicator.

## Interactions

Controls open focused sheets for color, asset selection, and widget ordering. Drag reordering has Move up/down alternatives. Preview expands full-screen. Leaving with unsaved local changes requires confirmation.

## States and accessibility

Loading preserves the last cached preview. Offline state disables Publish but allows local editing. Tabs and color swatches expose text labels. Touch targets are at least 44px and keyboard appearance never covers the active control.
