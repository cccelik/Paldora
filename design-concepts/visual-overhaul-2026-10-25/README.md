# Paldora visual overhaul concepts

Eight generated desktop and mobile design explorations. These are visual references, not implemented UI or product specifications. Preserve Paldora’s actual private Boxes, chronological feed, and existing features when adapting a direction.

`paldora-visual-directions-pitch.mp4` is a 44-second, 1080p overview of all eight directions with an original ambient soundtrack. `pitch-video-cover.png` is its closing card. Run `python3 make_pitch_video.py` from this directory or the repository root to regenerate the video (requires Pillow, NumPy, and FFmpeg).
