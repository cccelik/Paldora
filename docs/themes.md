# Themes

Application appearance (`light`, `dark`, or `system`) and a user's Room theme are separate preferences. Shared design tokens provide the Paldora palette: Obsidian Ink, Antique Gold, Champagne, Warm Ivory, and Soft Lavender.

Web and mobile render themes natively. Theme data will be a validated, versioned configuration rather than executable content. Initial presets will include Obsidian Gold, Cream Paper, Lavender Dream, Ocean Glow, Daisy Day, and Neon Night.

Arbitrary HTML is outside the initial milestone. Any later custom CSS must be scoped to the Room container; custom HTML must be sanitized, allowlisted, sandboxed, and isolated from navigation, privacy, security, billing, and moderation surfaces. JavaScript customization is prohibited.
